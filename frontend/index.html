PERFORMANCE INDEX

How the API is calculated

API = 100 × (0.30Y + 0.25P + 0.20W + 0.25R)

Y = normalized yield · P = normalized profit · W = normalized water efficiency · R = inverse normalized average disease/pest risk. Each component is percentile-clipped and scaled from 0 to 1. Weights are transparent project assumptions, not an official agricultural standard.
